haikai: privacy policy

haikai (com.abm.haikai) is a game for young children made by abm. It does not collect names, contact details, location or any advertising identifier. It sends a small amount of anonymous play data to abm, described below, which can be switched off.

Who is responsible

abm makes haikai and decides what the play data described here is used for (in data protection law, abm is the "controller"). You can reach abm at abm.ai.studios@gmail.com.

What the game collects

The game has no accounts and no sign-in. It asks for no name, email address, age, location, photos or contacts. It does not read the advertising ID, the phone number or any hardware identifier.

While "Share anonymous play data" is on in Settings (it is on at first), the game sends these things to abm's own server:

  • a random number made by the game when it is installed, and a second one for each time it is opened. They are not taken from the device and a reinstall makes a new one;
  • the game's version, the device model, the Android version, the screen size, the graphics type and the amount of memory;
  • what happened in play: which day was played and whether it was won, coins and stars earned, drinks served, customers who left, upgrades bought with in-game coins, settings changed, how long the game was open;
  • faults: the text of a program error and where in the game it happened.

The address the data comes from is used for a few seconds to limit how often one device may send, and is not stored.

Why, and who sees it

abm uses the data only to find and fix faults and to balance the game's difficulty. It is not used for advertising or to build a profile of anyone, and it is not sold or shared with anyone else. It is sent over an encrypted connection and kept on servers in the European Union (Amazon Web Services, Ireland), which store it for abm.

The legal ground

abm relies on its legitimate interest in keeping the game working and fairly balanced. The data is limited to what that needs, it does not identify a person, and anyone can switch it off in the game at any time. abm does not ask for consent to advertising or profiling because it does neither. In the terms of the United States children's privacy rule (COPPA), the random install number is used only to support the internal operations of the game.

How it is protected

The data travels over an encrypted connection (HTTPS) and is stored encrypted. Only abm can read it. The server accepts play data but gives none out, so nobody can read another player's data through the game.

How long it is kept, and how to stop it

Each record is deleted automatically 90 days after it arrives. To stop sending, open Settings in the game and switch "Share anonymous play data" off: the game then sends nothing and drops anything not yet sent. Because the data carries no name or account, abm cannot tell which records belong to a particular child; on request (see Contact) abm deletes the records of an install whose random number you can give us, and otherwise they expire within 90 days.

Ads and purchases

The game contains no advertising, no in-app purchases and no third-party software kits that collect data. The game engine's own statistics reporting is switched off. The only internet address the game talks to is abm's play-data server.

Where progress is kept

The café is saved in a small file on the device. If Android backup is switched on, Android includes that file in the device's own backup to the Google account on the device; abm cannot see it. Deleting the game deletes the save, and Settings in the game has a Reset progress button.

Children and parents

The game is designed for children and follows the Google Play Families policy. The play data described above is the only information collected from anyone, including children. It contains nothing that identifies a child, and it is used only to keep the game working and balanced. The game shows no advertising and has no links that lead a child out of the game.

A parent or guardian can at any time:

  • stop the sending: in the game, open Settings and switch "Share anonymous play data" off;
  • ask abm what play data it holds from a device, or ask abm to delete it, by writing to abm.ai.studios@gmail.com. Because the data carries no name or account, tell us the device model and the days on which the game was played so that we can find the records. We answer within 30 days;
  • do nothing: every record is deleted by itself 90 days after it arrives, and removing the game stops everything.

Your rights

Depending on where you live, you may have the right to see the data held about you or your child, to have it corrected or deleted, to object to its use, and to complain to your data protection authority. Write to abm.ai.studios@gmail.com to use any of these rights; you do not need to give a reason.

Changes to this policy

If a later version of the game changes any of this (for example by adding advertising or collecting anything more), this page and the statement inside the game (Settings, Privacy) will be updated before that version is released.

Contact

Questions about this policy: abm.ai.studios@gmail.com.
